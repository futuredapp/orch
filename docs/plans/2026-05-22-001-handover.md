## Design decisions worth knowing

These are baked into the U1-U3 code; don't second-guess them without reading the plan first.

1. **One socket per run, shared by `orch` and every per-source session.** The historical scratch session used a *different* socket variable in some test fixtures, but in production it was always the same socket. The refactor commits to one socket. Tests that previously had `SCRATCH_SOCKET` and `MAIN_SOCKET` are merged into one `SOCKET`.
2. **Pane ids are sticky to processes; `swap-pane` exchanges contents only.** The `panes` map stores the initial pane id from `createSession` and never updates it after a swap. `getPaneId(key)` returns the same pane id before and after any number of swaps. The new test `preserves the pane-id-sticky invariant` pins this.
3. **`destroy-unattached off` is now in `session-init.ts`'s appliance config**, not in scratch-session.ts. It must apply *before* any per-source session is created. The `-f` config file path achieves this — tmux reads the file before allocating the initial pane.
4. **Failure isolation by design (KTD3).** A `createSession` failure for source A no longer corrupts a shared substrate. Source B proceeds normally. The test `failure isolation: source B succeeds even when source A fails` pins this.
5. **`createSession` env/cwd flow through.** The plan only mentioned this in passing, but to preserve the existing PTY behavior (which used to flow env/cwd through `splitPane`), `CreateSessionOptions` gained optional `env` and `cwd`. `RealTmuxService.createSession` appends `-e KEY=VAL` and `-c <cwd>` flags before the trailing command argv.
6. **Lifecycle event vocabulary changed per KTD4.** New events fire (`source-session-*`); `pane-killed` and `pane-spawned` are preserved (replay tooling/finding-doc greps keep working). `scratch-window-rotate` is gone.
7. **Placeholder is the only source with a `cat` holder.** Every other source's initial pane is the source process itself. `commandForSpec(spec, key)` returns `SOURCE_HOLDER_ARGV` only for `key.type === 'placeholder'`.
